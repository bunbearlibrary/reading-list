# Keep Secret

**：杀了他这件事，我是谁这件事，爱着你这件事。**

**by. chang**

持枪的男人名叫郑允浩。他是老大的左膀右臂，这在组织里无人不知。他从未因任何人动摇过，经手的每一桩杀人案都缜密而干净，因此在这一行中恶名远扬。一米八出头的身高，锐利的眼神，放在哪里都不逊色的长相。他穿着一身漆黑的西装，像是量身定制般妥帖，裤线沿着他修长的腿笔直垂落，衬得整个人愈发夺目。

——郑允浩。

&nbsp;

"我没做错什么，允浩先生你也知道的。"

&nbsp;

红唇一张一合，毫不怯场，说完还心安理得地眨了眨眼——这个人叫金在中。金在中。恐怕知道他真名的人只有郑允浩一个，因为组织里的人都只叫他"顶楼的那位"。

三个月前，他被当作老大的玩物带到这里。可他倒好，大摇大摆地在公司各处闲逛，顶着那张漂亮的脸、穿着暴露的衣服招摇过市。允浩一把抓住他的手腕，把他拖回了顶层。被拽着踉踉跄跄往前走的时候，他也不怕，嘟着嘴犟着说自己没做错任何事。那时候是这样，现在也是这样。该说他可爱呢，还是不知死活。

&nbsp;

"……我还不想死。允浩先生，嗯？"

&nbsp;

而最近，也许是夫人察觉到了什么，又也许只是单纯地厌倦了——老大下了命令：让郑允浩去处理掉金在中。

连苍蝇都不如的命。照你说的，你确实没做错什么，除了生得太好看。

允浩缓缓举起枪，枪口抵上了在中的额头。冰冷的金属触感刚一贴上皮肤，那双浓密眉毛便细细地颤了起来，眉心微微蹙紧。在中用一双快要哭出来的眼睛仰望着允浩。

&nbsp;

"……我好好活过了啊。"

"……"

"也有了喜欢的人了啊。"

"……"

"快开枪吧。赶紧死掉，我好重新投胎。下辈子，允浩先生旁边那个位置是我的。是我的。我先占了。"

&nbsp;

说"是我的"时他还带着玩笑似的笑意，可眼角的肌肉分明在发抖，震动之间，眼泪沿着苍白的脸颊滑了下来。

"咔嗒"一声，子弹已经上膛。现在只要扣下扳机就好了。我会记住你的，记住你美得不可方物的样子。可上了膛之后，手指却久久地抵在扳机上动弹不得，颤抖了那么长时间——这从未有过。在中白皙的身体在发抖，泪水再一次划过他冰凉的面庞。允浩原本绷紧了脸，想让自己看起来冷酷一些，可那表情开始一点一点地崩裂。右手食指只要再动一动，这个美丽的造物就将永远从他眼前消失。

&nbsp;

"……允浩先生，我好喜欢你。"

"……"

&nbsp;

"好喜欢你"这四个字灼得胸口发痛。允浩重新咬紧了牙关，把力道集中到握枪的手上。他想起从小收养自己的老大的脸，又想起独自一人打工、把所有期望都寄托在自己身上的母亲。原本抿成一条线的嘴唇微微翘了一下，随即允浩闭上了眼睛。

&nbsp;

砰——

&nbsp;

装了消音器，但子弹射出的声响仍然让人不舒服。允浩将枪插回腰间，从口袋里掏出一张纸条放在桌上，转身走出顶层。他按下了地下二层的按钮，电梯缓缓下行。

&nbsp;

> *现在收拾东西。*
> *地下二层 W13。*

&nbsp;

老大的命令，他从来没有违抗过。这一次，是第一次。

母亲曾经对他说过一番话。她说，去守护那个在你眼中美好的人。哪怕全世界都叫你放弃，只要那个人在你心里是美好的，就要去守护他。允浩，妈妈会帮你的。

他靠在电梯的镜面墙上，大口大口地喘着气。这样做，真的可以吗。

&nbsp;

&nbsp;

"允浩先生。"

&nbsp;

在中像是刚哭过，眼眶里还蓄着泪。他匆匆收拾了几件衣物，背上包走了下来。允浩朝他招招手示意他快些过来，等在中上了车坐到后座，便一脚油门驶了出去。

&nbsp;

"谢谢。"

&nbsp;

是在说谢谢你没杀我吗。从一张看起来绝不会说出"谢谢"的嘴里听到这两个字，感觉很奇妙。在中长长地呼出一口气。外面应该很冷，他却只穿了薄薄的一层。允浩从后视镜瞥了一眼他的脸，踩下了油门。

他们正在逃亡。

&nbsp;

"妈，我回来了。"

"哎呀，允浩啊。"

"这个人——帮我照顾一下。"

&nbsp;

他打算在找到安全的落脚点之前，先把在中藏在母亲家里。在中瘦瘦的，背着包，穿着热裤露出大半截腿，规规矩矩地低头说了声"您好"。说实话，到现在允浩自己也不明白，自己为什么没有杀掉在中。母亲一如既往地和蔼，笑着招呼在中快进屋。在中小跑着跟了进去。

&nbsp;

"妈……我得走了。他这个人很脆弱，拜托您好好照顾他。"

&nbsp;

趁在中在屋子里四处张望的时候，允浩在母亲房间里把来龙去脉简单说了一遍。在中则用修长的手指东摸摸西碰碰。棕色的家具摆放得错落有致，算不上富裕，却处处透着允浩母亲的优雅品味。

&nbsp;

"小心啊。"

&nbsp;

临走前允浩对在中留下了这句话。在中落寞的脸让他心口一阵刺痛。在中只是用微笑作为回应。他没办法说出"别走"——他们犯下的事太大了。如果允浩放过自己这件事被组织知道，不光是自己和允浩，连允浩的母亲都会遭殃。

允浩的母亲让在中好好休息，把他领进了一间房。看起来像是允浩小时候用过的卧室。在中坐在那张床上叹了口气，这时门被推开，有人走了进来。

&nbsp;

"你谁啊？"

&nbsp;

跟允浩长得一模一样。在中吓了一跳，但仔细看，穿衣风格和郑允浩的喜好略有不同。在中有些局促，赶紧抱着包从床上站起来打了个招呼。这时允浩的母亲端着削好的水果走进来，给两人做了介绍。

&nbsp;

"来，认识一下。这是允浩的双胞胎弟弟。"

&nbsp;

啊……双胞胎。难怪总觉得哪里不太一样。不过那双凌厉的眼睛倒是如出一辙。

&nbsp;

"你叫什么来着？"

"金在中。"

"叫我J就行。我不兴起名字那套。"

&nbsp;

那个和允浩长得一模一样的男人一屁股倒在在中坐过的床上，单手撑着脑袋躺着。在中面对一张和允浩如此相似的脸，多少有些不自在。J拍了拍床边示意他坐下。允浩的母亲则拉来一把椅子让在中坐。母亲说要去田里干活便出了门，J和在中两个人沉默地待在房间里。

气氛尴尬极了。偏偏长了一张和我喜欢的人一模一样的脸。

&nbsp;

"哥，还在那儿上班呢？"

&nbsp;

允浩反复嘱咐过他。家里人不知道他在组织里做事，只以为他是个普通上班族。在中不知该怎么回答，支支吾吾说了半天废话，总算勉强应了一句。呼——好险。

&nbsp;

"……嗯，是。"

"那你们是同事？"

&nbsp;

在中回忆了一下他们是怎么认识的。在允浩面前，自己不是衣不蔽体，就是站都站不起来，要么干脆是昏迷的状态。怎么说得出口是"同事"啊。嘴角浮上一丝苦笑，在中含含糊糊地点了头。抛弃自己的老大的右臂，郑允浩。每一次面对自己赤裸的身体都别过头去，说着"我先出去"的、永远清心寡欲的郑允浩。

"啊？"

&nbsp;

&nbsp;

"我觉得你不会讨厌这种事的。"

&nbsp;

何其残酷。刚刚差点死在爱的人枪下，现在又要被一个和那个人长得一模一样的男人侵犯。
