# 大好き 永遠に

**by. chang**

---

&nbsp;

那年冬天，允浩真的很痛苦，痛苦了很久很久。光是待在他身边，就能真切地感受到他有多难受——那种痛像是直接渗进了我的心里、我的胸口。我恨自己总能那么敏锐地捕捉到这些。

在保姆车里，允浩无缘无故的叹息越来越多。他开始失眠，半夜呆坐在宿舍客厅发愣。他也会因为一些鸡毛蒜皮的事朝我发脾气，然后好几天不跟我说话。这样的日子越来越频繁。可每一次，他总会先喝醉了酒，红着眼眶跟我道歉，说对不起，请我原谅他。

"抱歉……最近烦心事太多了，总是忍不住拿你撒气。"

说完这些话，他就带我去了一家很不错的餐厅。我看着他眼角的肌肉微微颤抖，看着他费力地挤出笑容，心想，他真的快撑不住了。

"没事，咱俩多少年的交情了。"

允浩听完，忽然闭上了嘴。他从口袋里摸出一根烟——明明戒了很久了。为了点火，他微微低下头，下颌线以四十五度角倾斜着。我移开了视线，告诉自己，不该有的情绪不应该被翻出来。

"嗯，是啊。"

允浩平静地看着我，淡淡地应了一句。可他的眼神比刚才更疲惫、更沉重了。我知道那不仅仅是因为行程太满，不仅仅是累，也不仅仅是对未来的焦虑。成员们大多把这归结为"允浩哥的叛逆期来晚了"，就那样轻描淡写地翻了篇。但不是的。

有什么巨大的东西正在试图改变允浩。他拼了命地抵抗，不想被改变，可那东西却不肯放过他。

那一年就那么过去了，我始终没有弄明白那究竟是什么。允浩越来越瘦，脸色越来越苍白，叹气声越来越频繁。从前只在我面前才会撒的娇，也渐渐消失了。他站在那里，光是站着，都让人觉得他随时会倒下。我心里很不是滋味——难道我在你眼里，连这点事都不值得倾诉的朋友吗？

后来连这份委屈也顾不上了，取而代之的是纯粹的恐惧。他再这样下去会不会出事？是不是该带他去医院？

就在我忧心忡忡到了极点的那天，他终于开口叫住了我。

&nbsp;

"……我有一个爱的人，可是我不知道该怎么办。"

&nbsp;

说出这种令人脸红的话时，允浩丝毫不觉得难为情，神情认真得我好几年都没见过。他这个人虽然骨子里是认真的，但本质上是温柔而明快的。看着他这几个月天翻地覆的变化，我有些发怔。允浩见我愣住，温和地笑了笑。

我们是艺人。没有人逼我们走这条路，也不是心不甘情不愿。是我们自己选的，曾经也有过哪怕把灵魂卖给魔鬼、只要能站上舞台就好的日子。可正因为太多东西来得太快太猛，偶尔也会冒出"要是我不是艺人就好了"的念头——想和爱的人痛痛快快地接吻，不想让自己的爱情变成别人茶余饭后的谈资。

说起来，和允浩聊"爱情"这个话题，已经是很久很久以前的事了。我们太忙了，忙到根本无暇去想什么爱不爱的。

&nbsp;

"什么？"

"心跳加速，什么都想给他，想多碰他哪怕一次……是不是很奇怪。"

&nbsp;

莫名其妙地，我想哭。

原来这就是去年冬天允浩那么痛苦的原因……我告诉自己不要觉得委屈，可还是忍不住委屈起来。我甚至想立刻站起来、夺门而出。

&nbsp;

"你跟我说这些干什么。"

&nbsp;

我比谁都清楚，允浩除了我，没有第二个人可以商量这种事。但我还是没能藏住胸口那根尖锐的刺。

好痛。

&nbsp;

"……因为是你。"

"什么？"

"那个人就是你。"

&nbsp;

事实上，先喜欢上允浩的人是我。意识到那件事的那天，我就发过誓，死也不会说出口。我们从很久以前就是朋友，可允浩对我而言，从很久以前开始，其实就已经是"爱"了。

允浩的话让我震惊得合不拢嘴，只能用蜷起的手指挡住半张脸，呆呆地杵在原地。我觉得只要稍微动一下，这个瞬间就会碎掉。

允浩也是突然间才意识到的吗？我们之间的关系，如果只用"朋友"来形容……未免也太……

&nbsp;

"你说我该怎么办？能帮我出主意的人，只有金在中你一个啊。"

"……"

"你知道的吧，我最听你的话。你告诉我该怎么做就好。你说放下，我就放下。你骂我神经病，我就笑笑算了。你好歹说句话啊。"

&nbsp;

说到最后，允浩的声音已经劈了一半。然后他用极低的声音补了一句——"拜托了。"

他好像要哽住了，深吸了一口气，抬眼撞上我的目光时，用快要哭出来的眼睛冲我笑了笑。我依然一动不动，像一台死机的电脑一样看着他。

&nbsp;

"拜托了。我爱你。你好歹跟我说一句话吧。"

&nbsp;

那颗藏了那么久的心，被他突然叫了出来，反而想转身装作不认识。我一个人熬了多久你知道吗……我一个人有多难受你知道吗……你说得那么轻松，可我真的好委屈。

看着允浩深深地低下头盯着地面，我的眼泪不争气地掉了下来。

&nbsp;

"……呜、嗯……"

"你哭了？"

"……嗯……"

"你哭什么，想哭的人明明是我。"

"因为委屈，你这混蛋……"

"什么意思？"

"你这辈子都不会知道的……"

&nbsp;

"先喜欢上你的人是我"这句话，我死也不会说出口。自己到底在哭什么也说不清楚，只是止不住地掉眼泪。允浩从对面挪到我身边坐下，然后缓缓地、小心翼翼地揽住我的肩，把我拉进他的怀里。

很温暖。偏偏因为那份温暖，眼泪掉得更凶了。我想大喊一声"你放开！"，可不知不觉间已经窝在他怀里，安安静静地哭了起来。

&nbsp;

"从很小很小的时候起，一看到你，心就会莫名其妙地跳得很快。什么都想给你，想多碰你一下，一直都是这样。"

"……"

"你也知道我这个人，对谁都热情嘛。我一直以为你只是我特别喜欢的朋友——"

"……"

"可是不知道从什么时候开始，这份心越来越大了。"

"……"

&nbsp;

我就那样安静地靠着他。我没有回答好，也没有回答不好。因为不管是哪一种，都太沉重了。

&nbsp;

"就像以前那样对我就好，和平常一样。"

&nbsp;

也许他把我的沉默当成了拒绝，语气里满是遗憾。

&nbsp;

"就当是浓度高了一点的友情吧，你觉得呢？"

&nbsp;

允浩一边帮我擦眼泪，一边低下头和我对视。我不知道他以为我在为什么而哭，只是努力避开了他的目光。允浩温柔地笑了笑，那个表情分明是在说——谢谢你没有说"我再也不想见你"这样的话。他的心意就那样一点一点地渗过来，明明不想去感知，却怎么也挡不住，好难受。

那就是我们"浓度高了一点的友情"——那场恋爱的开始。

&nbsp;

---

&nbsp;

"允浩哥最近怎么天天笑嘻嘻的？"

"……啊，大概是叛逆期结束了吧。"

&nbsp;

有天和俊秀在化妆间里有一搭没一搭地聊着，我在旁边假装看镜子，心虚得不行。

&nbsp;

"怎么说呢，有点过于活泼了吧？"

"嗯，回来了。"

&nbsp;

又是一阵心虚。我对着镜子装模作样地照了照，心里想，允浩确实变回了以前的样子。不，应该说比以前更夸张了。

&nbsp;

"在中啊！！！"

&nbsp;

看吧，那不就飞奔过来了。他举着手里的汽水罐贴上我的脸颊。好冰！我抬头瞪他一眼，他笑得温温柔柔的。

&nbsp;

"哥，我们的呢？"

&nbsp;

爱喝汽水的俊秀开口了。允浩一脸歉意地说"抱歉啊没有——"，一边单手揉着坐在椅子上的我的肩膀。

&nbsp;

"哇，看看，就只惦记在中哥……"

"太过分了！！"

"你们也长得像在中这么可爱试试啊。"

"什么？你现在是以长相区别对待？"

"……嗯。"

&nbsp;

他"啵"地一声打开刚才贴过我脸颊的汽水，递到我面前。"喝吧。"

我小声嗯了一声，有些不好意思地接过来。那三个闹完别扭做完妆就各自散了，化妆间里不知怎的就只剩下了我们两个。

&nbsp;

"……被他们发现了怎么办？"

"发现了又能怎样。"

&nbsp;

笑嘻嘻的。允浩这阵子简直幸福得要死。

&nbsp;

"说实话，只要你不介意，我恨不得现在就告诉他们。"

"喂……"

&nbsp;

可一到了镜头前，他反而比谁都紧张，连指尖碰到我都要小心再小心。真是个可爱的家伙。我忍不住笑了。我们这样过了又不是一天两天。只是浓度高了一点的友情而已。只有我们自己知道的、那份浓度的密度。

&nbsp;

"在中啊，说出来以后真的好轻松。"

&nbsp;

为了和坐着的我平视，他弯下膝盖蹲在我面前对上我的眼睛。如果没有遇到这张脸、这个傻瓜，我的人生会是什么样呢……这么一想，又觉得还是遇到了好，遇到了真是太好了。

&nbsp;

"憋在心里的时候疼得要命……说出来以后，一下子就不疼了。"

&nbsp;

那双眼睛是真的释然了。我想，从痛苦中挣脱出来后的幸福大概就是这个样子。仔细看看，我们的允浩也不是当年那个毛头小子了。脸上到处都写着"我老了"三个字。幸好是一起变老的，我这样想着。

如果人生是一张巨大的画纸，每过一年就拿一支彩色铅笔往上涂一格色彩的话，那允浩和我一直在填同一格。也许明年我们会换一种颜色，也许那时候我们已经不在彼此身边了——但我们这二十几年填上的颜色是一模一样的，所以不必觉得遗憾。

&nbsp;

"喜欢你又不是我的错嘛~ 谁叫你长成那样~"

&nbsp;

大概是不想让气氛太沉，他换上一副调皮鬼的表情说了这番话。啊……我受不了了。不知道哪来的勇气，我俯下身，凑到允浩耳边，带着嘴角怎么也压不下去的笑意，很轻很轻地说——

&nbsp;

"大好き……永遠に。"

&nbsp;

允浩瞪圆了眼睛，惊讶地看向我——而就在那一瞬间，大门被推开，工作人员涌了进来。我若无其事地站起身走到另一边。允浩愣在原地，然后一屁股坐进了我刚才坐过的位子，抬头正好和我四目相对。我冲他漂漂亮亮地笑了一下，他这才慢慢地、微微地弯起了嘴角。

然后整整一天，他什么也没提。

录完日语专辑回家的车上，允浩双手十指交叉枕在脑后靠着椅背，去骚扰一旁闭眼休息的俊秀。

&nbsp;

"俊秀啊，你知道daisuki是什么意思吗？"

"哥，我们学了几年日语了，daisuki都不知道？"

"你就说嘛。"

"天哪，昌珉看不起我也就算了，哥你也看不起我？"

"我是真不知道才问的嘛，什么意思？"

&nbsp;

看看那张脸，能装。他不动声色地瞥了我一眼，我的脸烧得更厉害了，赶紧用手给自己扇风。

&nbsp;

"就是'喜欢、爱'的意思啊！！！"

"哇，是吗？这个意思啊？那eienni呢？"

"哥你是真的在看不起我吧？"

"俊秀哥肯定不知道吧！"

"沈昌珉！！你找死！！"

"昌珉啊，eienni是什么意思？"

"永远。"

"哦——原来是这个意思啊。"

&nbsp;

允浩安安静静地笑着，幸福得不像话。俊秀气鼓鼓的，昌珉觉得逗俊秀太有意思了，肩膀一抖一抖地闷笑。

&nbsp;

"那daisuki eienni呢？合在一起是什么意思？"

"永远爱你……吧。"

&nbsp;

有天替他们回答了。他就坐在我旁边，说完以后抬起头，忽然看向我。

&nbsp;

"在中哥你热吗？脸怎么这么红。"

"嗯……就，热。"

&nbsp;

允浩像是打算睡一会儿，十指交叉的手没有松开，只是换了个姿势窝进座椅里。

&nbsp;

"daisuki eienni……真是句好话，你们说是不是？"

&nbsp;

问完这句话，也不等谁回答，就这么闭上了眼。

三个人的表情写满了"郑允浩是不是疯了"，而我——我只是莫名其妙地脸烫得要命，恨不得揍他一顿。

可是很幸福。

幸福就够了，还要什么呢。
