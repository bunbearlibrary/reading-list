# 🐻YJlib🐰

> 助力🦔×🐖生十个

这是一个纯前端翻译文库，所有文本存放于 GitHub 仓库，通过 Pages 在线阅读。  
支持搜索、标签筛选、番外关联、夜间模式、字体调整。

## 📋 books.csv 字段说明

| 字段 | 说明 |
|------|------|
| `文件名` | 仓库中的 `.txt` 文件名，必须与文件一字不差 |
| `标题` | 显示用标题 |
| `作者` | 原作者笔名 |
| `状态` | 完结 / 未完 / 连载中 |
| `番外所属正文` | 若为番外，填写对应正文的文件名 |
| `类型标签` | 如 `postype`、`pixiv`，用顿号分隔 |
| `日期` | 更新日期，格式 `2026/7/20` |
